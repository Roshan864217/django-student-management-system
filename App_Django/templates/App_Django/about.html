About

Student Management System

A web application built with Django to manage students, teachers and courses from a single dashboard. It replaces manual record keeping with a centralized, searchable database.

Features

  • Student registration, update and delete with confirmation
  • Teacher and course management with teacher-to-course assignment
  • Dashboard with live statistics and students-per-course chart
  • Search and pagination on every list
  • Form validation with clear error messages
  • Django admin panel for back-office management

Tech stack: Python, Django, SQLite, HTML5, CSS3.
